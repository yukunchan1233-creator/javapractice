## 학습 예제 프로젝트

Java 기초 문법 학습용 예제 모음입니다. 각 클래스는 `main` 메서드를 포함하며 단독 실행이 가능합니다.

### 빠른 시작
```bash
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out basic.Basic01_print
```

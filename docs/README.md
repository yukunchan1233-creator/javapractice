## 프로젝트 문서 개요

이 문서는 저장소의 공개 API(여기서는 실행 가능한 `public class` 와 `main(String[] args)` 진입점)를 대상으로 목적, 사용법, 예제를 정리합니다. 코드베이스는 주로 Java로 작성되었고 `src/basic` 패키지에 학습용 예제들이 포함되어 있습니다.

- 실행 환경: JDK 17 이상 권장
- 빌드 도구: 필요 없음 (직접 `javac`/`java` 사용)
- 모듈: `src/module-info.java` 가 존재하지만 학습 예제 실행 시에는 클래스패스 방식 사용을 권장합니다.
